# 빨간펜 리뷰 루프

사람은 브라우저에서 HTML 위에 고칠 곳을 직접 표시하고, 너는 **이 대화의 맥락을 유지한 채** 그 표시를 받아 HTML(또는 내용이 들어 있는 JS 파일)을 고친다. 수정 요청에는 슬라이드 번호·원문·앞뒤 문맥·DOM 경로·소스 `파일:행`이 들어 있어서 페이지를 추측할 필요가 없다.

## 1. 시작

1. 대상 HTML을 정한다 — 사용자가 말한 파일, 없으면 이 대화에서 만들거나 고친 HTML. 후보가 여러 개라 애매하면 물어본다.
2. `redpen open <html>` 을 실행하고 출력된 주소를 사용자에게 알려 준다 (브라우저가 자동으로 열린다).
3. 한 줄로 안내한다: "텍스트를 드래그해 D(삭제)·R(수정)·C(코멘트), 배치는 '레이아웃'에서 끌어서 옮기고 모서리로 크기, 빈 곳은 '영역'으로 표시하고 [AI에게 보내기]를 누르세요."
4. 곧바로 2단계로 대기에 들어간다.

## 2. 수정 요청 기다리기

- **Claude Code**: `redpen wait <html>` 을 Bash 도구의 `run_in_background: true` 로 실행한다. 사용자가 [AI에게 보내기]를 누르면 명령이 끝나고 완료 알림이 오며, 그 출력(stdout)이 곧 수정 요청이다. 기다리는 동안 턴을 마쳐도 된다.
- **Codex 등 백그라운드 실행이 없는 환경**: `redpen wait <html> --timeout 540` 을 명령 타임아웃 10분(600000ms) 이상으로 실행한다. 종료 코드 2(시간 초과)면 같은 명령을 다시 실행한다. 사용자가 천천히 볼 것 같으면 "다 보내면 알려 주세요"라고 하고 턴을 끝낸 뒤, 알려 오면 `redpen pending <html>` 로 가져온다.

## 3. 반영

- 출력의 `#번호` 항목을 **하나도 빠짐없이** 반영한다. 출력 맨 위의 "반영 규칙"을 따른다.
- 🗑 **삭제**: 그 텍스트·요소·슬라이드만 지우고, 비게 된 태그와 남는 구두점·공백도 정리한다.
- ✏️ **수정**: `원문` → `변경` 그대로 바꾼다. 굵게·링크 같은 주변 서식은 유지한다.
- 💬 **코멘트**: `지시`를 해석해 반영한다. 대상이 영역이면 위치(예: "오른쪽 위")와 "영역 안 요소"를 참고한다.
- 📐 **레이아웃**: 사람이 화면에서 직접 옮기고·키우고·순서를 바꿔 본 결과다. 그 모습이 되도록 HTML/CSS를 고치되 `translate`나 절대 좌표로 흉내 내지 말고, "지금:"에 적힌 원래 방식(flex·grid·몇 번째 칸)에 맞게 순서·크기·간격·글자 크기를 바꾼다. %·px는 목표값 참고용이다.
- 📐 **새 배치 스케치**: 칸의 위치·비율과 이름대로 슬라이드를 다시 구성한다("지금 그 자리" = 지금 그 칸에 있는 요소). **슬라이드 순서 옮기기**는 슬라이드를 통째로 그 번째로 옮긴다.
- 내용이 HTML이 아니라 JS(예: `slides.js`)에 있으면 그 파일을 고친다 — `소스: 파일:행`을 참고한다 (편집 전 기준이므로 여러 곳을 고칠 땐 문자열로 찾는다).
- 같은 문구가 여러 곳이면 슬라이드 번호·문맥(⟦ ⟧ 안이 표시한 부분)·소스 후보로 정확한 위치를 고른다.
- 요청하지 않은 곳은 건드리지 않는다. 지시가 모호하면 가장 합리적으로 해석하고 그 해석을 답장에 적는다.
- 파일을 저장하면 브라우저가 자동으로 새로고침된다.

## 4. 결과 알리고 다음 라운드

- 반영이 끝나면 `redpen wait <html> --reply "<무엇을 바꿨는지 1~3문장 · 못 한 항목은 이유>"` 를 다시 **백그라운드로** 실행한다. 답장이 브라우저에 뜨고 다음 수정 요청을 기다린다 → 2단계로.
- 사용자에게도 같은 내용을 짧게 말한다.
- 사용자가 리뷰를 끝내자고 하면 `redpen done <html> --reply "<요약>"` 을 실행한다 (기다리던 wait도 함께 끝난다).

## 수동 모드

기다리는 세션 없이 사용자가 먼저 보냈다면("리뷰 반영해줘"): `redpen pending <html>` → 반영 → `redpen done <html> --reply "..."`.

## 참고

- `<html>` 을 생략하면 마지막으로 연 파일을 쓴다. 폴더를 주면 그 안의 `index.html` 을 연다.
- 슬라이드 번호가 이상하면(감지 실패) `redpen open <html> --slide "<슬라이드 요소 선택자>"`.
- `redpen status <html>` 상태 확인 · `redpen stop <html>` 서버 종료.
- `redpen` 명령이 없으면 사용자에게 설치를 안내한다: 빨간펜 저장소 폴더에서 `node bin/redpen.mjs setup` (또는 `npm link`).
- 리뷰 데이터는 `<HTML 폴더>/.redpen/` 에 저장되며 git에서 자동 제외된다.
